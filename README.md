# 국내외 주요뉴스 브리핑 웹앱

## 실행
Python 3.9 이상이 설치된 컴퓨터 또는 서버에서 프로젝트 폴더를 열고 아래 명령어를 실행합니다.

```bash
python server.py
```

같은 기기의 브라우저에서 `http://localhost:8787`을 열어 뉴스 화면을 확인하십시오. 실행 시 Google 뉴스의 공개 RSS 검색 결과를 수집합니다. 네트워크가 필요합니다. 별도 Python 패키지 설치는 필요하지 않습니다.

## 주요 기능
- 국내·해외의 경제·사회·정책 6개 검색 범주
- 유사 제목의 기사를 근사적으로 묶어, 서로 다른 매체 수 우선으로 정렬
- 보도 원문 링크, 카테고리 필터, 수동 갱신

## 유의사항
- 검색 RSS 표본 기반 **추정 순위**로서 실제 전체 언론사의 보도량 순위가 아닙니다.
- 한국어·영어 기사는 동일 사건이라도 별도로 묶일 수 있습니다.
- 뉴스 원문을 직접 요약하거나 서버 자체에서 예약 알림을 전송하지는 않습니다.
- 오전 7시 30분 정기 브리핑은 별도로 설정된 ChatGPT 예약 작업으로 제공됩니다.
- iPhone에서 홈 화면에 설치하려면 공개 HTTPS 서버에 배포해야 합니다. localhost로 실행한 PC의 주소를 아이폰에서 바로 열 수는 없습니다.
- 공개 배포 시 접근 통제, 요청량 제한, 캐싱, 서비스 운영 모니터링을 추가하는 것이 좋습니다.
